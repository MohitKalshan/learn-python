# Python Basics

A collection of beginner-friendly Python scripts covering core language features and data structures, with notes aimed at preparing for DSA (Data Structures and Algorithms).

## Contents

| File | Topic |
| --- | --- |
| `array.py` | Lists as arrays: indexing and appending |
| `slicing.py` | List slicing syntax (`start:stop:step`) |
| `looping.py` | `for`/`while` loops, `range`, `enumerate`, nested loops, `break`/`continue` |
| `conditions.py` | `if`/`elif`/`else`, nested conditions, membership/identity operators, ternary expressions |
| `stack.py` | Stack (LIFO) using a list: push, pop, peek, size, empty check |
| `queue.py` | Queue (FIFO) using a list and `collections.deque` |

## Requirements

- Python 3.x

No third-party dependencies are needed.

## Running the examples

Run any file directly:

```bash
python3 array.py
python3 slicing.py
python3 looping.py
python3 conditions.py
python3 stack.py
python3 queue.py
```

Each file prints the output of its examples and includes inline comments explaining the concepts.

## Notes

- `conditions.py` includes a Java vs Python cheat sheet for common operators and syntax.
- `slicing.py` and `queue.py` include notes on the time and space cost of list operations, which matters in DSA problems.
